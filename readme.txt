== Description ==
Echo Media Shield is a unique, PHP-only WordPress utility designed to enhance image presentation with a customizable "shield" effect. This plugin allows users to wrap their images in a distinct visual border and an interactive hover overlay, displaying custom text. Focused on simplicity and efficiency, it provides a straightforward way to add an "echo style" media presentation without relying on external files or complex setups. Users can easily configure the shield's appearance, including enabling/disabling the shield, border color, overlay text, and overlay background/text colors, directly from the WordPress admin settings. Images are embedded using the `[echo_media]` shortcode, supporting either media attachment IDs or direct image URLs.

This plugin is open source. Report bugs at: https://github.com/ogichanchan/echo-media-shield
